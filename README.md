# Seven Excellent 203

Arsip digital resmi Kelas 7E, SMPN 203 Jakarta.

Dibuat oleh **Rafardhan Athala**.

## Tentang Project

Website ini adalah arsip digital untuk Kelas 7E, tempat menyimpan data siswa, foto kegiatan, jadwal pelajaran, dan informasi seputar kelas supaya bisa dibuka kembali kapan saja, bahkan setelah tahun ajaran berakhir.

Project ini dibangun menggunakan **Next.js** (React dengan TypeScript) untuk bagian aplikasi, dan **Tailwind CSS** untuk styling tampilan.

Proses development dibantu oleh AI agent **[opencode](https://opencode.ai)** untuk mempercepat penulisan kode. Meskipun begitu, seluruh ide, konsep, struktur halaman, dan logika di project ini murni hasil pemikiran sendiri. AI di sini hanya berperan sebagai alat bantu eksekusi, bukan sumber ide atau keputusan desain.

## Fitur

- Profil dan arsip foto 36 murid kelas 7E
- Galeri kegiatan kelas
- Jadwal pelajaran
- Halaman tentang kelas

## Cara Menjalankan di Komputer Sendiri

Panduan ini ditulis untuk yang belum pernah menjalankan project Next.js sebelumnya.

### 1. Install Node.js

Project ini butuh Node.js untuk bisa jalan. Kalau belum punya, download dulu di [nodejs.org](https://nodejs.org/) (pilih versi LTS), lalu install seperti biasa. Setelah selesai, cek apakah sudah terpasang dengan membuka terminal (Command Prompt, PowerShell, atau Terminal di Mac) lalu ketik:

```bash
node -v
```

Kalau muncul nomor versi (misalnya `v20.x.x`), berarti sudah berhasil.

### 2. Download project ini

Kalau sudah punya Git, jalankan:

```bash
git clone https://github.com/VernsDS/Seven_Excellent203.git
cd Seven_Excellent203
```

Kalau belum familiar dengan Git, bisa juga download langsung lewat tombol hijau Code di halaman GitHub repo ini, pilih Download ZIP, lalu extract ke folder pilihanmu dan buka folder itu lewat terminal.

### 3. Install semua library yang dibutuhkan

Di dalam folder project, jalankan:

```bash
npm install
```

Perintah ini akan mengunduh semua package yang dipakai project. Prosesnya bisa memakan waktu beberapa menit tergantung koneksi internet.

### 4. Jalankan project

Setelah instalasi selesai, jalankan:

```bash
npm run dev
```

Tunggu sampai muncul tulisan seperti `Local: http://localhost:3000` di terminal, lalu buka alamat tersebut di browser. Website akan tampil dan otomatis update setiap kali ada perubahan kode.
