# Seven Excellent — Design Direction

## Creative direction

Combine school community, editorial design, and a modern digital archive.

The website should feel premium, personal, youthful, refined, organized, and authentic.

It must not feel like a generic school template, SaaS dashboard, children's website, or AI-generated landing page.

## Visual north star

Every major visual should reinforce:
1. Identity
2. People
3. Memory
4. School life
5. Community

## Installed skills

Use:
- UI/UX Pro Max for UX/design-system intelligence.
- Taste Skill for visual taste, composition, typography, motion, and anti-slop.
- Ponytail for engineering restraint and dependency discipline.

## Typography

Use a maximum of:
- one display family
- one body family
- optional monospace accent

Create a clear hierarchy from display → heading → body → metadata.

## Color

Use a restrained near-black/deep-neutral foundation, graphite surfaces, high-contrast text, one strong identity accent, and optionally one secondary accent.

Do not make every element glow.

## Hero

The hero must establish:
- Seven Excellent
- 7E
- SMPN 203 Jakarta
- concise explanation
- primary CTA
- secondary CTA
- meaningful dimensional visual

CTA must be above the fold.

## 3D / dimensional visual

Use one meaningful dimensional system, such as:
- 7E geometric sculpture
- digital yearbook
- class archive
- editorial photo composition

Possible implementation: CSS 3D, React Bits, React Three Fiber, Three.js, or optimized pre-rendered assets. Choose the lightest option that works.

Avoid random spheres, blobs, cubes, and particles.

## Motion

Motion should be smooth, controlled, and purposeful:
- page reveal
- subtle parallax
- image interaction
- navigation transitions
- card hover
- dimensional movement

Respect `prefers-reduced-motion`.

## Composition

Avoid repeating:
Heading → Paragraph → 3 Cards.

Use varied compositions:
- editorial hero
- typographic statistics
- asymmetric leadership
- directory grid
- image mosaic
- structured timetable
- editorial about section

## Students

The directory should feel like a curated class archive. Prioritize names and absent numbers. #17 Maulana Aliffian may receive subtle visual distinction as Class President.

## Gallery

Prioritize real class photography. Use varied aspect ratios and intentional visual rhythm.

## Images

Prefer AVIF/WebP and responsive loading. With Next.js, use `next/image` where appropriate.

Do not use random stock people as fake class memories.

## 404

Create a branded custom 404 rather than a framework default.

## Anti-slop

Avoid excessive:
- glassmorphism
- neon
- gradients
- huge rounded cards
- blobs
- particles
- random 3D
- pills
- shadows
- generic SaaS sections
- fake statistics
- fake testimonials
- fake logos

If an effect does not improve identity, hierarchy, usability, depth, or storytelling, remove it.

## Premium test

The final result should look intentionally designed through typography, spacing, composition, authentic content, meaningful motion, and restrained dimensional visuals.
