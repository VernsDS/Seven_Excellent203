## Skill roles

UI/UX Pro Max → UX and design-system intelligence.
Taste → visual quality, composition, typography, anti-slop.
Ponytail → engineering restraint and dependency discipline.

## Rules

- Inspect existing code before modifying it.
- Preserve working architecture when reasonable.
- Do not add dependencies without a reason.
- Do not fabricate class information.
- Keep student data centralized.
- Keep images replaceable through data.
- Prefer server components when using Next.js unless client behavior is required.
- Optimize images.
- Respect reduced motion.
- Test responsive layouts.
- Run lint/typecheck/build before completion.
- Never declare the project complete with a broken production build.

## Design rule

Premium does not mean more effects.

Prefer:
intentional typography + composition + spacing + authentic imagery + purposeful motion.
